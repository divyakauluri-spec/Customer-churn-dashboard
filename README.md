# Customer Churn Analysis — Telco Dataset

An interactive dashboard and Power BI report analyzing customer churn patterns using the Telco customer dataset. The project highlights key churn drivers, customer segments at risk, and retention insights through visual analytics.

## Live Demo

View the live dashboard: https://divyakauluri-spec.github.io/Customer-churn-dashboard/churn_customer_dashboard.html

## Contents

| File | Description |
|------|--------------|
| churn_customer_dashboard.html | Interactive web dashboard (HTML/CSS/JS) — no installation needed, view directly in browser |
| Customerchurnanalysis.pbix | Power BI report — open with Power BI Desktop (Windows only) |

## About the Project

This analysis explores customer churn behavior to identify:
- Key factors driving customer attrition
- Demographic and service-based churn patterns
- High-risk customer segments
- Retention opportunities based on usage and billing data

## Viewing the Dashboard

Online: Click the live demo link above — works on any device, no setup required.

Locally: Download churn_customer_dashboard.html and open it in any modern browser (Chrome, Edge, Firefox).

## Power BI Report

Open Customerchurnanalysis.pbix in Power BI Desktop to explore the full interactive report, including drill-downs and filterable visuals.

## Built With:
- HTML, CSS, JavaScript (dashboard)
- Power BI (report)
- Telco Customer Churn dataset
